02 · Tipografía

Fuentes

En Ajustes del sitio → Fuentes globales. Los títulos van en una grotesca ultra-negra; el texto en una sans limpia y legible.

Archivo Black
Títulos, logo, precios y botones. Mayúsculas, pesada, con carácter. (Google Fonts, gratis)
Space Grotesk
Texto, menús y descripciones. Moderna y neutra. Alternativa segura: Inter.
03 · Logo

Uso del logo PF

Badge cuadrado → favicon e ícono en móvil. Horizontal → cabecera del sitio.

Súbelos en Apariencia → Personalizar → Identidad del sitio (logo e ícono). Reglas de marca:

  • Siempre PF blanco con contorno navy sobre el badge magenta.
  • Mantén el borde navy grueso y la sombra dura (no lo aplanes).
  • Aire libre alrededor: mínimo el ancho de la letra “P”.
  • Nunca lo estires ni cambies el magenta por otro tono.
04 · Montaje

Reconstruir la home en Elementor

Sigue el orden. Cada bloque es una sección de Elementor con su fondo y sus columnas.

  1. Barra superior de aviso
    Sección delgada, fondo #1B1B3A, texto amarillo centrado: “ENVÍO MUNDIAL · −10% CON EL CÓDIGO GOAL10”.
  2. Cabecera + logo
    Usa Elementor → Plantillas → Theme Builder → Header. Logo PF a la izquierda, iconos (🔍 ❤ 🛒) a la derecha con el widget de menú/íconos.
  3. Menú en píldoras
    Widget Nav Menu centrado. En Avanzado aplica el CSS de píldoras (abajo): borde navy, colores alternos, sombra al pasar el ratón.
  4. Hero amarillo
    Sección fondo #FFD23F, borde navy 4px, radio 24px, sombra 8px 8px 0 #1B1B3A. Titular Archivo Black con “GOL.” en magenta con contorno. Botón navy.
  5. Franja de garantías
    4 columnas (Envío / Personalización / Pago / Devoluciones), cada una con su color de fondo y borde navy.
  6. Productos
    Widget WooCommerce → Products. Muéstralo en cuadrícula de 4. El estilo de tarjeta (borde + sombra dura) se aplica con el CSS de abajo.
  7. Footer
    Theme Builder → Footer. Fondo navy, borde superior magenta, “PF JERSEYS ⚽” en amarillo y enlaces.
  8. WhatsApp flotante
    Plugin Click to Chat, botón verde abajo a la derecha.
05 · CSS

CSS de marca (pégalo tal cual)

En Apariencia → Personalizar → CSS adicional (o Elementor → CSS personalizado). Da a los botones, menús y tarjetas de producto el look neo-brutalista.

:root{
  --pf-mag:#ff2d78; --pf-mag-d:#d6155c; --pf-ink:#1b1b3a;
  --pf-yellow:#ffd23f; --pf-teal:#06d6a0; --pf-cream:#fff3e0;
}

/* Fondo general */
body, .elementor-kit-1 { background:var(--pf-cream); }

/* Menú en píldoras */
.pf-menu .menu-item a{
  border:3px solid var(--pf-ink); border-radius:999px;
  padding:.5rem 1.1rem; margin:.25rem; font-weight:700;
  background:#fff; transition:.12s; display:inline-block;
}
.pf-menu .menu-item:nth-child(2n) a{ background:var(--pf-yellow); }
.pf-menu .menu-item:nth-child(3n) a{ background:var(--pf-teal); }
.pf-menu .menu-item a:hover{
  transform:translate(-2px,-2px); box-shadow:3px 3px 0 var(--pf-ink);
}

/* Botones (incluye Añadir al carrito) */
.pf-btn, .woocommerce a.button, .woocommerce button.button{
  background:var(--pf-ink) !important; color:var(--pf-yellow) !important;
  border:0 !important; border-radius:999px !important;
  font-weight:800 !important; text-transform:uppercase;
  box-shadow:4px 4px 0 var(--pf-mag-d);
  transition:.12s;
}
.pf-btn:hover, .woocommerce a.button:hover, .woocommerce button.button:hover{
  transform:translate(-2px,-2px); box-shadow:6px 6px 0 var(--pf-mag-d);
}

/* Tarjetas de producto WooCommerce */
.woocommerce ul.products li.product{
  background:#fff; border:3px solid var(--pf-ink); border-radius:18px;
  box-shadow:5px 5px 0 var(--pf-ink); padding:1rem;
  transition:.14s;
}
.woocommerce ul.products li.product:hover{
  transform:translate(-3px,-3px); box-shadow:8px 8px 0 var(--pf-ink);
}
.woocommerce ul.products li.product .price{
  color:var(--pf-ink); font-weight:800; font-size:1.15rem;
}

/* Titulares con carácter */
.pf-title{ font-family:"Archivo Black",sans-serif; text-transform:uppercase; }
.pf-title .accent{ color:var(--pf-mag); -webkit-text-stroke:2px var(--pf-ink); }

💡 Al widget de menú ponle la clase CSS pf-menu y a los botones manuales pf-btn (pestaña Avanzado → Clases CSS de Elementor).
